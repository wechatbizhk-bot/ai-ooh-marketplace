LBS = Location-Based Services

Location-Based Services use a device's position to decide what to show it. On this marketplace the same idea works in both directions: the advertiser pulls the inventory near a shop, and the network can push a different creative when a location, a time or a condition makes it more relevant.

How the position is established

🛰GPS satellites
Metre-level outdoors — the source behind “use my location”.
📡Cellular tower signals
Works indoors and between buildings, at lower precision.
📶Wi-Fi triangulation
Reliable inside malls and offices where GPS struggles.
🔵Bluetooth beacons
Room-level triggers: “standing at this counter”.

Pull — the user asks

An advertiser searches the map for inventory near a shop, filters by radius, sorts by distance and books what is free — the same shape as searching for a nearby coffee shop. The user starts the query.

Push — the system offers

The network can push a different message when a condition is met — local weather, lunchtime, an event crowd or a beacon entry — exactly like a local weather alert or a store promotion arriving unbidden.
